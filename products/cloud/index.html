Экосистема TRASSIR Cloud

Экосистема TRASSIR Cloud позволяет работать с облаком как с самостоятельным решением, так и использовать его в связке с другими продуктами.

Камеры
TRASSIR Cloud

TRASSIR Cloud может работать как самостоятельное решение, чаще всего для небольших объектов: подключаются камеры, которые работают с TRASSIR Cloud напрямую и не требуют для работы регистратора или сервера.

VMS
TRASSIR Cloud

TRASSIR Cloud может работать как часть экосистемы, расширяя возможности вашей VMS системы.

Возможности облачного сервиса TRASSIR Cloud

  • Отображение видео высокого качества в режиме реального времени
  • Хранение записей от 3 до 120 дней для подключенных камер
  • Масштабируемое централизованное хранение архивов
  • Быстрый доступ к архиву из любой точки мира
  • Удаленный доступ к архиву видеозаписей из любой точки мира
  • Быстрый доступ к архиву, хранящемуся по облаку
  • Безопасное хранение архива
  • Быстрое масштабирование функционала видеонаблюдения

Доступные опции

  • Камеры и регистраторы
  • Облачные камеры (Wi-Fi и GSM)
  • Видеоаналитика для облачных камер
  • Серверы
  • TRASSIR Merge для серверов
  • Server Pro
