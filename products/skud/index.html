Система контроля и управления доступом

Решаем задачи бизнеса

Управление персоналом

  • Создание и редактирование персон
  • Добавление дополнительных полей персонам
  • Добавление фото персоне
  • Гибкий поиск персон
  • Временные персоны (блокирование)
  • Настройка погрешности при распознавании и маскировании автономеров

  • Синхронизация данных персон через Active Directory
  • Тегирование
  • Создание макетов пропусков

Управление доступом

  • Определение уровней доступа
  • Многофакторная идентификация
  • Запрет повторного прохода Antipassback (локальный и глобальный)
  • Шлюз (аппаратный и программный)
  • Доступ по температуре тела
  • Отчетность по измерениям температуры
  • Открытие дверей из мобильного приложения TRASSIR
  • Удобный поиск и просмотр событий
  • Фотоидентификация
  • Гибко настраиваемый интерфейс оператора
  • Доступ с подтверждением и без проверки прав
  • Доступ с подтверждением алкотестером
  • Отчет по алкотестированию
  • Доступ по состоянию объектов
  • Доступ из веб-браузера
  • Ограничение по кол-ву объектов в зоне
  • Интеллектуальное детектирование нарушений проходов

  • Шаблоны отчетов
  • Строгий учет рабочего времени
  • УРВ по дням

  • Статистика по сотрудникам
  • Отчет об опозданиях
  • Отчет по всем проходам сотрудников
  • Отчет о нахождении в определенной зоне
  • Контроль количества сотрудников на объекте
  • Учет данных нейросетевого модуля

Возможности TRASSIR СКУД

Интегрированная система безопасности

Видеонаблюдение, видеоаналитика и СКУД объединены в общую систему безопасности с прозрачной логикой работы.

Общая система безопасности
ВидеонаблюдениеВидеоаналитикаСКУД

Централизованное управление

Все компоненты системы управляются из единого центра: это повышает защиту и ускоряет реакцию на инциденты

Экономия и простота

Одна платформа для начала работы, понятный интерфейс и простая логика настройки.

Мультивендорная СКУД

Поддержка оборудования других вендоров (турникеты, двери, шлагбаумы, лифты).

Удобное решение для распределенных объектов

Позволяет организовать единую систему учета рабочего времени и контроля доступа на распределенных объектах с управлением из головного офиса.

Гибкая кастомизация

Правила, сценарии и открытый API дают широкие возможности для адаптации под задачи бизнеса.

Высокий уровень безопасности

Расширенные сценарии управления доступом, интеграция с видеонаблюдением и видеоаналитикой позволяют повысить уровень контроля и безопасности на объекте и исключить человеческий фактор при обработке тревог.
